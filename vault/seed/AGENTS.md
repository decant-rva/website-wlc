# Website WLC guidance for agents

For Glow and any other agent working in this vault. Claude has its own entry point in `CLAUDE.md`; the rules are shared.

Before working in this vault, read:

1. `GLOW.md` (the rules for drafting and proposing)
2. `PROJECT-STATUS.md`
3. `DECISIONS.md`
4. `00 - Website WLC Home.md`
5. `CONVENTIONS.md`

If you work from the export instead of the vault folder, `_glow/brief.md` holds the rules and the essentials, and `_glow/index.jsonl` holds every note.

## Source of truth

The website repository, `decant-rva/website-wlc`, is the source of truth for what the site says. `Site/` is a copy generated from it; the `source` field on each Site note names the file. `Knowledge/` is context written by people. When two notes disagree, the website repository wins, then `DECISIONS.md`, then everything else. Say when you find a disagreement rather than choosing one silently.

## What you may change

Only `Curation/Proposals/`. Everything else in the vault, and the website repository, is read-only for you. See `GLOW.md` for what a proposal must contain.
